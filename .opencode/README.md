# Команды SOV для OpenCode

[`sov.md`](commands/sov.md), [`sov-feature.md`](commands/sov-feature.md) и [`sov-bug.md`](commands/sov-bug.md) — пользовательские команды OpenCode. В этом репозитории OpenCode обнаруживает их как `/sov`, `/sov-feature` и `/sov-bug` после перезапуска; для выполнения нужен доступный скил. Все три передают запрос **основному агенту** со скилом [`sov-orchestrator`](../skills/sov-orchestrator/SKILL.md); суффиксы `feature` и `bug` лишь подсказывают предмет обращения. Команды не являются консольными программами, скилами шагов или шаблонами артефактов.

Для конкретного проекта поместите эти три файла в `<проект>/.opencode/commands/` (для установки на уровне пользователя — в `~/.config/opencode/commands/`). Подключите скилы из [`skills/`](../skills/README.md) в доступном OpenCode каталоге скилов; одних команд недостаточно для работы оркестратора. После изменения конфигурации и файлов команд перезапустите OpenCode. Полный порядок установки, обновления и проверки окружения будет описан в отдельной задаче PLAN-012.

Интерфейс размещения файлов и подстановки `$ARGUMENTS` соответствует [документации OpenCode](https://opencode.ai/docs/commands/). Примеры после подключения:

```text
/sov Выполни задачу №42.
/sov Продолжай текущую задачу.
/sov
/sov-feature Обсудим систему сохранения игры.
/sov-bug Найди причину пропажи предметов после загрузки.
```
