---
description: Передать поручение оркестратору SOV или продолжить текущую задачу
---

Используй скил `sov-orchestrator` как основной агент для этого поручения. Загрузи его инструкцию и следуй ей; если скил недоступен, сообщи об этом вместо имитации его работы.

Запрос пользователя (может быть пустым):

<request>
$ARGUMENTS
</request>

При указанном ID проверь назначение и состояние задачи. При пустом запросе или просьбе продолжить без ID сначала через `sov-tasks` найди незавершённые задачи устойчивого исполнителя из правил проекта: одну продолжи (при `blocked` сообщи препятствие), при нескольких запроси ID, при нуле выбери первую доступную `planned`. Это правило действует и в новой сессии после перезагрузки: не опирайся на память прежнего диалога. Новый запрос без ID обрабатывай как отдельное поручение. Определи результат и границы по запросу, состоянию задачи и правилам проекта.
