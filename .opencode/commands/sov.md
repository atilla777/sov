---
description: Передать поручение оркестратору SOV или продолжить текущую задачу
---

Как основной агент используй скил `sov-orchestrator` для запроса пользователя по правилам подключённого проекта. Определи результат прежде маршрута: обсуждение может завершиться ответом без задачи; для тривиальной разработки предложи быстрый маршрут для этого поручения и дождись согласия прежде пропуска обычных шагов. Проверку подключения, выбор и продолжение задачи выполняй по инструкции оркестратора; если скил или подключение недоступны, сообщи о препятствии.

Запрос пользователя (может быть пустым):

<request>
$ARGUMENTS
</request>
