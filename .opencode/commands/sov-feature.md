description: Обсудить фичу или передать задачу по фиче оркестратору SOV
---

Сначала проверь, что текущий проект подключён к SOV: его правила указывают закреплённую версию ресурсов, их пути и работающий источник задач, а доступный `sov-orchestrator` относится к этой версии. Глобальная видимость команды не доказывает подключения. При отсутствии подключения или конфликте версий сообщи о препятствии, не выбирай задачи. Затем используй скил `sov-orchestrator` как основной агент для этого поручения; если скил недоступен, сообщи об этом вместо имитации его работы.

Подсказка о теме: фича. Это не разрешение на разработку или публикацию за пределами запроса пользователя. Если он просит только обсудить фичу или подготовить требования, не начинай реализацию.

Запрос пользователя (может быть пустым):

<request>
$ARGUMENTS
</request>

При указанном ID проверь назначение и состояние задачи; при пустом запросе или просьбе продолжить без ID в том числе в новой сессии сначала продолжи единственную незавершённую задачу устойчивого исполнителя по `sov-tasks`, при нескольких запроси ID, при отсутствии выбери первую доступную `planned`. При `blocked` сообщи препятствие без переключения. Файловый список меняй только через `sov-tasks` с проверенным `sov-state`; до подтверждения назначения не начинай работу, при конфликте пересмотри выбор, при потере ответа перечитай состояние. Новый запрос без ID обрабатывай как отдельное поручение. Определи результат и границы по запросу, состоянию задачи и правилам проекта.
