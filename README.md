# SOV

SOV — набор взаимосвязанных Agent Skills и шаблонов артефактов для разработки с агентами в OpenCode. Принципы работы описаны в [спецификации](docs/sov-spec.md), действующий файловый учёт — в [SOV Tasks](docs/specs/filesystem-tasks.md).

## Агенту, устанавливающему SOV в проект

Установка или обновление подключения — отдельное поручение для конкретного проекта. Сначала прочитай его `AGENTS.md`, `rules/index.md`, `docs/index.md` и применимые требования, затем [спецификацию SOV](docs/sov-spec.md) и [пошаговую инструкцию первой установки и обновления](docs/install-filesystem-tasks.md). Для поручения обновить установленный выпуск используй [скил `sov-update`](skills/sov-update/SKILL.md) вместе с [процедурой обновления](docs/install-filesystem-tasks.md#обновление-действующего-подключения). В инструкции также приведены порядок бережной правки проектного `AGENTS.md` и [адаптируемый пример](docs/install-filesystem-tasks.md#проектный-agentsmd).

Перед запуском `/sov` проверь в проекте закреплённый commit и абсолютные пути выпуска SOV, подключённый `skills.paths`, расположение команд и субагентов OpenCode, бинарник `sov-task` и общий каталог `.sov/` основной копии. Видимость глобальной команды сама по себе не означает, что проект подключён. Существующее подключение и работающие сеансы переключают только по процедуре обновления из инструкции; публикация этого репозитория их не обновляет.
