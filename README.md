# SOV

SOV — проект набора взаимосвязанных Agent Skills и шаблонов артефактов для разработки с агентами в средах типа OpenCode. Цель, границы и предполагаемый порядок работы описаны в [спецификации принципов работы](docs/sov-spec.md). Скилы и команды SOV пока не реализованы; этот репозиторий содержит исходную спецификацию и основу для дальнейшей разработки.

## Навигация

- [Спецификация SOV](docs/sov-spec.md) — исходные принципы и намеченные интерфейсы.
- [Руководство для агентов](AGENTS.md) — правила разработки самого SOV и ведения задач.
- [Индекс документации](docs/index.md) и [индекс правил](rules/index.md).
- [MIT License](LICENSE).

## Планируемая структура

`skills/` предназначен для исходников скилов SOV, `templates/` — для шаблонов артефактов. Продуктовые требования и решения будут размещаться в `docs/specs/` и `docs/adrs/`, правила разработки — в `rules/`. Состав и реализация будут определяться будущими согласованными задачами.
