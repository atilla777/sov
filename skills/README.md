# Скилы SOV

Здесь находятся исходники скилов, описанных в [спецификации](../docs/sov-spec.md). Первый скил — [`sov-tasks`](sov-tasks/SKILL.md), инструкция по учёту задач через файловый список целевого проекта. Остальные скилы пока не реализованы.

При установке в среду, поддерживающую Agent Skills, разместите папку `sov-tasks/` в каталоге скилов или настройте путь к ней. Наличие исходника здесь само по себе не подключает скил к OpenCode.
