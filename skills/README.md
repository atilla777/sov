# Скилы SOV

Здесь находятся исходники скилов, описанных в [спецификации](../docs/sov-spec.md). Реализованы [`sov-tasks`](sov-tasks/SKILL.md) — инструкция по файловому учёту задач, [`sov-git`](sov-git/SKILL.md) — инструкция по Git, worktree и прямой публикации в `main`, [`sov-okf`](sov-okf/SKILL.md) — оформление документов по принятому профилю целевого проекта, [`sov-spec`](sov-spec/SKILL.md) — обсуждение фичи и подготовка требований, [`sov-review-spec`](sov-review-spec/SKILL.md) — независимое ревью продуктовых требований, [`sov-decompose`](sov-decompose/SKILL.md) — явно запрошенная декомпозиция опубликованной Spec, [`sov-plan`](sov-plan/SKILL.md) — техническое планирование разработки, [`sov-research`](sov-research/SKILL.md) — диагностика ошибок и адресная перепроверка вывода, [`sov-implement`](sov-implement/SKILL.md) — реализация, тесты и проверки, [`sov-review-implementation`](sov-review-implementation/SKILL.md) — независимое ревью результата реализации, [`sov-orchestrator`](sov-orchestrator/SKILL.md) — управление поручением, шагами и завершением. [Команды OpenCode](../.opencode/README.md), включая `/sov-decompose` и `/sov-retro`, находятся отдельно.

[`sov-retro`](sov-retro/SKILL.md) — аналитический скил явно запрошенного ретро задач и сессий; трассы необязательны и читаются через отдельный официальный скил Langfuse при подтверждённой связи с задачей.

При установке в среду, поддерживающую Agent Skills, разместите папки скилов в каталоге скилов или настройте путь к ним. Наличие исходников здесь само по себе не подключает скилы к OpenCode.

Модели OpenCode для уровней `standard` и `advanced` задаются [двумя проектными субагентами](../templates/opencode/agents/), устанавливаемыми по [инструкции подключения](../README.md#первое-подключение). Скилы не привязаны к именам конкретных моделей.
