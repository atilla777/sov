# Скилы SOV

Здесь находятся исходники скилов, описанных в [спецификации](../docs/sov-spec.md). Реализованы [`sov-tasks`](sov-tasks/SKILL.md) — инструкция по файловому учёту задач, [`sov-git`](sov-git/SKILL.md) — инструкция по Git, worktree и публикации через GitHub, [`sov-okf`](sov-okf/SKILL.md) — оформление документов по принятому профилю целевого проекта, [`sov-spec`](sov-spec/SKILL.md) — обсуждение фичи и подготовка требований, [`sov-review-spec`](sov-review-spec/SKILL.md) — независимое ревью продуктовых требований, [`sov-plan`](sov-plan/SKILL.md) — техническое планирование разработки, [`sov-research`](sov-research/SKILL.md) — диагностика ошибок и адресная перепроверка вывода, [`sov-implement`](sov-implement/SKILL.md) — реализация, тесты и проверки. Остальные скилы пока не реализованы.

При установке в среду, поддерживающую Agent Skills, разместите папки скилов в каталоге скилов или настройте путь к ним. Наличие исходников здесь само по себе не подключает скилы к OpenCode.
