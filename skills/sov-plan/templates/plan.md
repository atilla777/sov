# Технический план — <задача>

> `sov-plan` готовит пригодный план перед реализацией разработки или исправления. Для новой функциональности опирается на опубликованные требования в `docs/` целевого проекта; для однозначного бага без отдельной спецификации — на ожидаемое поведение в `task.md`, не противоречащее опубликованным источникам, и пригодный результат `sov-research`. План не заменяет продуктовые требования и не проводит диагностику; готовый план не нужен до начала `sov-plan`.
