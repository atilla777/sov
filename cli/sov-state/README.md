# sov-state

Исходники вспомогательной CLI SOV версии **0.1.0**, протокол JSON **v:1**. Она выполняет байтовые `read` и условный `commit` существующего `.sov/ROADMAP.md` на Linux и локальной ФС. CLI не анализирует Markdown и не заменяет скил `sov-tasks`. Установка бинарника, подготовка постоянного mutex и переключение писателей относятся к PLAN-018 и PLAN-019; параллельная работа пока не включена.

Контракт аргументов, ответов и границы гарантий описаны в [проекте локальной CLI](../../docs/shared-state-cli-proposal.md#2-предлагаемый-контракт-cli). Команда `--version` выводит JSON с `message: "sov-state 0.1.0 (protocol v:1)"`. Успех `read` пустого файла возвращает `content_base64: ""` (пустое поле присутствует в JSON), как и для любого другого файла.

Для разработки требуется Go 1.25.4 или совместимая более новая версия. Из этой папки: `go test -race ./...`; сборка: `go build -o /tmp/sov-state .`. Не запускайте `commit` для проекта, где остальные писатели ещё редактируют ROADMAP напрямую.
