# Список задач SOV

> Образец только для первого создания списка в основной папке целевого проекта `.sov/ROADMAP.md` при остановленных писателях. После инициализации `sov-tasks` читает и меняет список через настроенный `sov-state read/commit`; другие скилы не обращаются к файлу напрямую. Не копируйте образец поверх существующего списка.

Строки идут в порядке выбора новых задач. Для нового проекта задайте неизменяемый префикс ID и устойчивый идентификатор исполнителя в правилах проекта до создания первой задачи; для независимых одновременных исполнителей нужны разные ID, номера задач растут последовательно и не используются повторно. ID сессии не подходит для восстановления после перезагрузки. `—` означает отсутствие исполнителя или зависимостей. В зависимостях перечисляются существующие ID через запятую; в публикации используется `yes` или `no`. Общие статусы: `planned`, `in_progress`, `blocked`, `done`, `cancelled`. Причины и подтверждения хранятся в локальном `task.md` задачи, а не в этой таблице. Перестановку строк и изменение любого поля проводите через `sov-tasks` с условной записью всего списка.
