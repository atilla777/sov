# Список задач SOV

> Образец только для первого создания списка в основной папке целевого проекта `.sov/ROADMAP.md` вместе с [`ARCHIVE.md`](ARCHIVE.md) при остановленных писателях. После инициализации `sov-tasks` читает и меняет список через настроенный `sov-state`; другие скилы не обращаются к файлам напрямую. Не копируйте образец поверх существующего списка.

| ID | Название | Статус | Исполнитель | Зависит от | Публикация |
| --- | --- | --- | --- | --- | --- |

Строки идут в порядке выбора новых задач. Для нового проекта задайте неизменяемый префикс ID и устойчивый идентификатор исполнителя в правилах проекта до создания первой задачи; для независимых одновременных исполнителей нужны разные ID, номера задач растут последовательно и не используются повторно. ID сессии не подходит для восстановления после перезагрузки. `—` означает отсутствие исполнителя или зависимостей. В зависимостях перечисляются ID задач, остающихся в этом списке, через запятую; в публикации используется `yes` или `no`. Общие статусы: `planned`, `in_progress`, `blocked`, `done`, `cancelled`. Терминальная задача без зависимых строк переносится в `.sov/ARCHIVE.md`; следующий ID и порядок очереди при этом сохраняются. Причины и подтверждения хранятся в локальном `task.md` задачи, а не в таблице. Перестановку строк и изменение любого поля проводите через `sov-tasks` с условной записью.
