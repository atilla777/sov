# Документация SOV

- [Исходная спецификация принципов работы](sov-spec.md) — назначение, границы и предполагаемые правила SOV.
- `specs/` — место для будущих согласованных продуктовых спецификаций.
- `adrs/` — место для будущих архитектурных решений.

Документы в `specs/` и `adrs/` появятся по мере согласования соответствующих задач.
