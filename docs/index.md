# Документация SOV

- [Спецификация принципов работы](sov-spec.md) — поручение, шаги, проверки и публикация; описания прежнего протокола помечены как исторические.
- [SOV Tasks — файловая система управления задачами](specs/filesystem-tasks.md) — действующие требования к учёту задач вместо общего списка; CLI и исходные скилы обновлены, переключение установок выполняется отдельно.
- [Исходники `sov-task`](../cli/sov-task/README.md) — CLI файлового ядра с проверенным просмотром завершённых карточек, используемая новыми инструкциями скилов.
- [Подключение файловых задач](install-filesystem-tasks.md) — первая установка, проверка worktree и контролируемый переход существующего проекта.
- [Результаты сквозной проверки PLAN-038](plan038-results.md) — изолированный маршрут файловых задач, конкурентный захват, прерывания и границы проверки публикации.
- [Результаты проверки методики PLAN-044](plan044-results.md) — изолированная цепочка требований, декомпозиции, передачи контекста и исправления замечания с границами моделирования.
- [Результаты сквозной проверки PLAN-013](e2e-results.md) — фактически проверенные маршруты и ограничения.
- [Результаты проверки исправлений PLAN-024](plan024-results.md) — маршруты бага, интерактивная сессия OpenCode, внешняя установка и границы проб.
- [Результаты проверки уровней моделей PLAN-025](plan025-results.md) — реальные субагенты, настройка моделей, работа из worktree и ограничения проверки.
- [Проект локальной CLI для общего списка задач](shared-state-cli-proposal.md) — историческое решение прежнего протокола.
- [Результаты проверки прежнего параллельного режима PLAN-020](parallel-state-results.md) и [порядок его включения в целевом проекте](parallel-activation.md).
- [Исходники `sov-state`](../cli/sov-state/README.md) — локальный протокол `v:1` и сборка прежнего выпуска; [прежняя подготовка бинарника](../README.md#подготовка-общего-бинарника-sov-state-linux).
- [Проверенное чтение `sov-tasks-view`](../cli/sov-tasks-view/README.md) — read-only диагностика двух таблиц и просмотр задач, без записи и автоматического подключения в проект.
- [Оценка PLAN-032 по MOY-019](plan032-results.md) — фактические свидетельства, границы измерения и показатели до/после.
- `specs/` — согласованные продуктовые спецификации.
- `adrs/` — место для будущих архитектурных решений.

Документы в `adrs/` появятся по мере согласования соответствующих задач.
