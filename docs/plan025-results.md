# Проверка уровней моделей SOV — PLAN-025

4 октября 2026 года проверена конфигурация OpenCode на отдельном локальном проекте `/tmp/opencode/sov-model-trial` и его Git worktree `/tmp/opencode/sov-model-trial-worktree`. Пробный проект и конфигурация действующих целевых проектов не публиковались и не переключались. OpenCode использовал доступные `openai/gpt-6-luna` и `openai/gpt-6-sol`; обе модели показала команда `opencode models openai`.

| Сценарий | Фактический результат |
|---|---|
| Агентские файлы по умолчанию | Установленные из `templates/opencode/agents/` файлы обнаружены командой `opencode debug agent sov-standard` как `mode:subagent`, `openai/gpt-6-luna`, и `opencode debug agent sov-advanced` как `mode:subagent`, `openai/gpt-6-sol`. |
| Реальный вызов через `task` | `opencode run -m openai/gpt-6-sol` вызвал `sov-standard` как дочернего агента; тот прочитал `sov-plan` и работал на Luna. **Прямой** `opencode run --agent sov-standard` не является такой проверкой: OpenCode предупреждает «subagent, not a primary agent» и использует основного агента. Инструкция установки уточнена по этому наблюдению. |
| Настройка проекта | В **копии** проектного `sov-standard.md` поле `model` изменено на `openai/gpt-5.6-luna`. Новые вызовы `task` из основной копии и worktree фактически использовали `openai/gpt-5.6-luna` для `sov-standard` и прежний `openai/gpt-6-sol` для `sov-advanced`. Оба файла агентов и `opencode.json` присутствовали в коммите тестовой базовой ветки до создания worktree. Исходный шаблон SOV остался с GPT-6 Luna. |
| Автор и независимое ревью | В пробной задаче `TASK-001` с согласованным поведением `greet(name)` новый `sov-advanced` вызван для `sov-spec`: созданы локальный `spec.md`, `docs/specs/greeting.md`, ссылка в `docs/index.md`. **Следующий отдельный вызов** `sov-advanced`, не автор, выполнил `sov-review-spec`, проверил сценарии и ссылки и записал отдельный `review.md` без изменения спецификации. Оба вызова сообщили `openai/gpt-6-sol`. Проверены фактические файлы; замечаний у пробного ревью не было. |
| Основной агент и режим без записи | `opencode run --agent plan --command sov -m openai/gpt-6-luna` сохранил `plan` и Luna; при просьбе создать задачу остановился до записи и указал переход в `build`. `opencode run --agent build --command sov -m openai/gpt-6-sol` сохранил `build` и Sol, выбрал standard для обычного плана и advanced для ревью. Команда не задавала другую модель основному агенту. |

Это проверяет обнаружение, фактические вызовы двух уровней, проектную кастомизацию, отдельное ревью и остановку в `plan` **на указанных сценариях**. Пробный проект не имел remote и общей установленной очереди задач: полный маршрут выбора, публикации PR и модельное повышение сложного технического плана не выполнялись; правило повышения и отказ при отсутствии модели проверены по инструкциям и конфигурации, но не как полный маршрут с изменением статуса. Установка действующих проектов требует отдельного обновления с проверкой их пользовательских конфигураций и перезапуском OpenCode.
