# Проверка общего файлового состояния — PLAN-020

4 октября 2026 года на отдельном временном локальном Git-проекте с двумя worktree выполнен [воспроизводимый сценарий](../tests/parallel_state_trial.py) с двумя **отдельными процессами** Python, вызывающими один собранный из исходников `sov-state 0.1.0 (protocol v:1)` с одним абсолютным `state-dir` и постоянным mutex. Пробный проект удаляется после проверки; работающие проекты и OpenCode-сессии не мигрировались.

Команды из корня SOV (для установленного Go через `mise` версия выбиралась только на время команды):

```sh
MISE_GO_VERSION=1.25.4 go test -race ./...           # в cli/sov-state/
MISE_GO_VERSION=1.25.4 sh cli/sov-state/build-candidate.sh /tmp/opencode/.sov-state-plan020
python3 tests/parallel_state_trial.py /tmp/opencode/.sov-state-plan020
```

Все команды завершились успешно. Скрипт проверил совпадающие read из двух worktree, гонку за `TASK-001` с выбором свободной `TASK-002` проигравшим, сохранение правок двух разных строк после пересборки при конфликте, выдачу разных ID `TASK-003`/`TASK-004` двум создателям, восстановление после потерянного ответа по смысловому результату без дублирования `TASK-005`, продолжение после записи строки до создания `task.md`, сохранность inode mutex, отказ для устаревшего revision и отсутствующего состояния. Сброс исходного списка между сценариями выполнялся **только в изолированной фикстуре при отсутствии писателей**.

Go-тесты CLI отдельно подтвердили: только один успех при общем expected, чтение целой версии при заменах большого файла, остановку до `rename` без публикации, ошибку после `rename` с `may_have_committed:true`, снятие `flock` после убийства владельца, `lock_timeout`, no-op, неверные входы, alias/symlink/hardlink и отсутствие автоматического восстановления исчезнувшего списка или mutex. Эти тесты проверяют байтовый протокол; скрипт проверяет применение правил повторного чтения и пересборки к конкретным задачам. Фактические интерактивные команды `/sov*` двух одновременных OpenCode-сессий, выдача разрешений OpenCode и переключение живого целевого проекта **не запускались**: это обязательные проверки при включении в каждом целевом проекте по [процедуре](parallel-activation.md). Ни CLI, ни сценарий не доказывают правильность всех возможных семантических решений агента.
